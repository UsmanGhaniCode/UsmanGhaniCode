### ⚡ What I bring to a team

- 🏗️ **Architecture that scales**: clean, SOLID, event-driven Unity code that a team can grow without rewrites
- 🌐 **Real-time multiplayer**: rooms, voice and chat with Photon PUN and Fusion, shipped in live metaverse projects
- 🥽 **XR and installations**: AR, VR and MR apps, plus depth-camera interactive wall games
- 📱 **Ship to stores**: mobile titles designed, built and published to the stores with Soar Games
- 🚀 **Performance**: profiling, memory and Addressables work to keep games smooth on mobile
